About

Five years of Java, Spring Boot and Flutter,

spent on systems where failure is expensive

— aviation information systems, banking

authentication, real-time video pipelines.

I work at the point where a specification becomes a running system. At FundastA that means taking Japanese interface-control documents and turning them into message schemas, validation rules and integration services for an aviation information-management platform built for a major Japanese aerospace client.

Before Japan I spent five years shipping mobile and backend products across fintech, media and education: liveness detection and OTP flows for a microfinance bank, a video-processing pipeline that survives bad networks, an ATM-monitoring platform, a learning system for schools. Different domains, same job — make the thing reliable, then make it explain itself when it isn't.

I like the unglamorous parts: integration testing, transmission state, why the queue drained but the client never updated. I'm most useful on a team that owns something people depend on.

Experience

Lagos, then London, now Nagoya. Six roles, read from the present backwards. The through-line is the same one every time: own the thing end to end, and make it explain itself when it breaks.

May 2026 — Present

Systems Engineer

FundastA — Nagoya, Japan

FundastA builds an aviation information-management platform for a major Japanese aerospace client. I work on the backend and on the seams between systems — the services that move operational information between web applications, backend components and aircraft-facing systems, and the message contracts that keep them all honest. A good part of the job is translation: Japanese interface-control documents in one hand, production services in the other. The rest is diagnosis, because in a distributed system the interesting failure is never where the error appears.

Sep 2024 — 2026

Senior Software Engineer

Pingtop — London, UK (remote)

A social video app, which meant living inside the media pipeline. I led the editing capabilities — overlays, voice-over, music, compression — and rebuilt the upload path so it survives a bad connection: retries, background compilation, recoverable state. Real-time processing in FFmpeg and AVFoundation is a permanent negotiation between output quality, device heat and server cost. Dart isolates and native bridges kept the interface responsive while all of that ran underneath it.
